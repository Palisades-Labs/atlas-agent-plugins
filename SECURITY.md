# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest Atlas plugin release and its pinned CLI | Yes |
| Earlier releases | No |

Security fixes are released in new immutable versions. Upgrade to the latest Atlas plugin release when a fix becomes available.

## Reporting a vulnerability

Email `support@atlasprospect.ai` with the affected plugin and CLI versions, impact, and reproduction steps. Do not open a public issue for an unpatched vulnerability.

We aim to acknowledge reports within three business days and provide an initial assessment within seven business days. Remediation timing depends on severity and the release process.

Before running a downloaded CLI binary, follow [Verify a download](README.md#verify-a-download).
